# Feuille de route

Idées pour la suite, par ordre de valeur. Les contributions sont bienvenues (voir CONTRIBUTING.md).

- [ ] **Anglais** : l'interface est en français ; extraire les textes (i18n) et traduire.
- [ ] **Import de recettes** depuis une page web ou une photo (l'IA lit, le code vérifie comme dans l'Atelier).
- [ ] **Autres catalogues de produits** : un adaptateur par drive, sur le modèle de `src/lib/chronocatalog.ts`.
- [ ] **Objectifs → recettes** : utiliser la cible de chacun dans la proposition de la Semaine et l'Atelier (aujourd'hui, la part s'adapte, le choix des recettes un peu).
- [x] **Guide visuel du rythme** (sport) : en plus du son et du bonhomme, une bille qui suit une courbe (comme sur l'écran de certaines machines de sport) : elle monte et descend au tempo exact de chaque phase (descente, pause, montée), en avance sur le geste, pour caler son rythme d'un coup d'œil, sur ordinateur comme sur téléphone.
- [ ] **Course** : coaching de course à pied par personne, d'après [course.md](course.md) (zones, charge, analyses des sorties, plan de reprise, séances vers la montre).
- [ ] **Séance à deux** : aligner les repos (« Ensemble »).
- [ ] **Santé** : Android (Health Connect), en plus d'Apple Santé.
- [ ] **Partage** : exporter une recette ou un programme en fichier, l'importer ailleurs.
- [ ] **Image Docker publiée** (GitHub Container Registry) pour éviter le build local.
